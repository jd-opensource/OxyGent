📖平台概述

OxyBank 是一个 AI 资产管理平台，用于管理结构化数据资产（Bank）。平台支持文档上传与切分、数据标注、自动化Agent流水线、向量检索等功能，为AI应用提供高质量的数据基础设施。

💡核心概念

Bank（数据银行）—— 数据的容器，类似于数据库中的"表"。每个Bank有自己的Schema（字段定义），支持自定义字段或选择预设场景模板。
Sample（样本）—— Bank中的每条数据记录。样本有状态流转机制（如 Imported → Annotated → Published），支持版本历史追踪。
Schema（数据模式）—— 定义Bank中样本的字段结构，包括字段名、类型（text/keyword/integer/float）和描述。
Agent（标注代理）—— 外部AI服务，当样本状态变化时自动触发，实现自动化标注流水线。
Template（标注模板）—— 定义标注界面的表单结构，控制哪些字段可编辑、编辑方式（单选/下拉/文本）等。

🚀快速开始

  1. 使用管理员账号登录系统（默认账号：admin / admin）
  2. 在「Bank管理」页面创建一个新的Bank，选择场景模板或自定义Schema
  3. 在「数据管理」页面上传文档或通过API存储数据
  4. 在「标注工作台」对样本进行人工标注或配置Agent自动处理
  5. 在「API Test」页面测试检索接口，集成到您的AI应用中

🧩字段与检索机制

Bank 中的字段分为「系统字段」和「用户自定义字段」两类，每个字段都可以在检索接口中被用作过滤条件或向量检索条件。理解字段与检索的映射关系，有助于合理设计 Bank 结构。

系统字段（sys_*）

所有 Bank 通用的预设字段，由系统自动生成和维护，不需要用户手动定义：

  • sys_sample_id / sys_document_id：样本和文档的唯一ID
  • sys_status：样本状态（如 Imported / Annotated / Published），驱动Agent触发
  • sys_executor、sys_priority、sys_template、sys_overview、sys_remarks、sys_create_time、sys_update_time：执行人、优先级、标注模板（可填模板 name 或 UUID）、摘要、备注、时间戳等元数据
  • sys_chunk：文档切分后的文本块（仅当 Bank 创建时勾选「启用文档切分」才启用）。这是唯一支持向量检索的系统字段。

用户自定义字段

创建 Bank 时通过 Schema 定义，或通过场景模板自动生成。可以是 text/keyword/integer/float 等类型，可任意命名（不能以 sys_ 开头）。

例如 memory 场景模板包含 query（问题）、answer（答案）、experience（经验）三个自定义字段。

检索模式

创建检索接口时，可以为每个字段选择检索方式：

  • exact（精确匹配）：字段值完全相等才命中，适用于状态、ID等分类字段
  • in（IN匹配）：字段值在给定列表中命中，适用于多选过滤
  • fuzzy（模糊匹配）：全文关键词匹配，适用于文本内容检索
  • vector（向量检索）：将查询文本 embedding 后，与该字段的向量做相似度排序

向量检索规则

  • 可做向量检索的字段：sys_chunk（唯一支持的系统字段）+ 所有用户自定义字段。其他 sys_* 字段（如 sys_status）不能设为 vector 模式。
  • 存储位置：向量字段会在 Vearch 向量数据库中生成一列 {field}_vector（如 experience → experience_vector），并调用 embedding 模型生成向量。
  • 多字段联合向量检索：一个检索接口可以配置多个字段为 vector 模式，系统会对每个字段的向量距离求和排序（Vearch 原生多向量检索）。
  • 过滤字段同步：接口中作为 exact/in/fuzzy 使用的字段（含 sys_* 字段）会一并存入 Vearch space，供向量检索时做原生过滤。

数据存储流程

Bank 内部同时使用 Elasticsearch 和 Vearch 两套存储：

  • Elasticsearch：完整的样本数据（所有字段），用于结构化查询和列表展示，也是数据的"权威副本"
  • Vearch：仅存放向量列 + 过滤字段的精简副本，专为向量相似度检索优化
  • Deposit 时：样本先写入 ES；若样本至少一个向量字段有内容，会生成 embedding 并写入 Vearch。若所有向量字段都为空，则暂不写入 Vearch。
  • 修改样本时：更新 ES 后自动同步 Vearch —— 若 Vearch 中已存在该样本，做增量更新（含 re-embed 变更的向量字段）；若不存在但更新后向量字段有值了，则 upsert 一条完整的 Vearch doc。
  • Agent 场景：常见用法是 deposit 时向量字段为空，等 Agent 触发后再写入内容。此时 Agent 通过 sample update API 修改数据，系统会自动完成 Vearch 的 upsert（生成向量、写入 Vearch）。

Vearch 索引重建

当 Bank 的检索接口或字段发生结构性变化，导致 Vearch space schema 与 ES 数据不匹配时，可以通过 POST /api/banks/{bank_name}/rebuild-vearch 接口重建 Vearch 索引：删除旧 space、按当前 retrieval APIs 创建新 space、扫描 ES 中所有样本重新生成 embedding 并批量写入。

典型使用场景：数据在 ES 里存在但检索接口返回 0 条时；或修改了 Bank 的检索接口配置后。前端设计上，Bank 创建后一般不允许修改检索接口，以避免这种不一致。

📦Bank管理

管理所有数据Bank的入口。支持创建、查看、删除Bank。创建Bank时可以选择：

  • 场景模板：提供QA问答、Memory记忆、客服FAQ、知识库、产品目录等预设模板，快速创建带标准Schema的Bank。
  • 自定义Schema：手动添加字段定义，或上传CSV/XLSX文件自动解析表头为字段。

创建Bank时还可以配置检索接口，定义检索条件（精确匹配、模糊检索、IN匹配、向量检索）和输出字段。

📂数据管理

管理Bank中的文档和样本数据。支持两种数据导入方式：

  • 文件上传：支持 DOCX、PDF、TXT、Markdown、CSV、XLSX 格式。文本类文件会自动切分为多个chunk并生成向量；表格文件每行作为一条样本。
  • API存储：通过 JSON 接口批量导入数据，适合程序化数据导入场景。

样本列表支持按状态筛选、查看详情、编辑字段、查看修改历史等操作。

✏️标注工作台

标注人员的核心工作界面，采用左右分栏布局：

  • 左侧：样本列表，支持按状态筛选，显示进度统计。
  • 右侧：样本详情与标注表单。根据绑定的标注模板，动态渲染可编辑字段（支持文本输入、单选、下拉选择等控件）。

标注流程：选择样本 → 填写/修改字段 → 点击「保存」推进状态，或点击「驳回」退回上一状态。

🤖标注Agent

配置自动化标注Agent。Agent是外部AI/服务，当样本状态发生变化时自动被调用。

  • 配置项：Agent名称、服务URL、触发状态（当样本变为该状态时触发）、启用/禁用开关。
  • 状态流转图：可视化展示所有Agent组成的状态流转链路，直观了解自动化处理流程。
  • 执行日志：记录每次Agent调用的输入状态、输出状态、耗时、成功/失败等信息。

🔌API Test

Bank的API文档与在线测试工具。展示当前Bank的所有接口：

  • 存储接口：支持单条存储和批量存储，提供curl和Python示例代码。
  • 检索接口：支持默认检索（全字段精确匹配）和自定义检索接口，可在线发送请求测试。
  • 工具发现：获取Bank的标准化工具描述（JSON Schema格式），可直接用于LLM/Agent的工具调用集成。

📋标注模板

管理标注工作台使用的表单模板。模板定义了哪些字段可编辑及其编辑方式。

  • 手动创建：选择可编辑字段，配置字段约束（单选/下拉/文本框）、选项值、条件显示规则等。
  • AI生成：通过对话描述需求，AI助手自动生成模板JSON配置。支持多轮对话迭代优化。

创建后可使用测试功能，输入样本数据预览模板的渲染效果。

模板是全局共享的：系统内置模板与用户创建的模板一起放在同一个全局池，任何 Bank 都可以使用池中任意模板。

样本与模板的关联：每条样本通过 sys_template 字段绑定一个模板。该字段接受两种值 —— 模板 UUID 或模板名字（推荐后者，更直观）。标注页面会根据样本的 sys_template 自动加载对应模板；Deposit / Agent 修改样本时，直接写入模板名字即可（模板名字全局唯一）。

👥用户管理

管理系统用户（仅管理员可见）。支持创建、编辑、删除用户。

系统有两种角色：admin（管理员）拥有所有权限；annotator（标注员）仅能访问标注工作台。

⚙️系统设置

配置系统运行参数（仅管理员可见）：

  • 标注设置：最大并发数（同时处理的Agent调用数）、Agent超时时间。
  • Embedding设置：Triton推理服务器URL，或OpenAI兼容API的地址和模型。
  • 文档切分设置：文本切分的块大小和重叠大小（tokens）。

❓常见问题

如何重置管理员密码？
系统首次启动时会自动创建默认管理员账号（admin / admin）。您可以在「用户管理」页面修改任何用户的密码。
支持哪些文件格式？
支持 DOCX、PDF、TXT、Markdown (.md)、CSV、XLSX 格式。文本类文件会自动切分并生成向量embedding。
如何对接外部AI服务作为标注Agent？
Agent需要提供一个HTTP POST接口，接收包含样本数据的JSON请求，返回修改后的字段值和新状态。在「标注Agent」页面配置Agent的服务URL和触发状态即可。
标注员能看到哪些页面？
标注员（annotator角色）仅能访问「标注工作台」页面，其他管理功能对标注员不可见。
如何将Bank集成到LLM应用中？
在「API Test」页面使用「工具发现」功能，获取Bank的标准化工具描述（包含inputSchema），将其作为工具传给LLM即可实现工具调用集成。
为什么我 deposit 了数据但向量检索返回 0 条？
如果 deposit 时向量字段（如 experience）是空的，系统会跳过 Vearch 写入（Vearch 要求向量字段非空）。等标注 Agent 或人工填写向量字段后，系统会自动补充 Vearch 记录。如果长时间未同步，可以调用「重建 Vearch 索引」接口手动修复。
一个检索接口可以配置多少个向量字段？
无限制。多个向量字段会被联合检索：每个字段各自做相似度计算，最终按各字段距离之和排序返回。
